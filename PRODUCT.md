# blue maruya

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

A private cinema website for discovering movies and series, saving a watchlist, and resuming playback.

## Users and Operating Context

Three existing member profiles: Waken, Kristine, and Guest. Movie-night use on desktop and phones. The user requested redesigned dashboards and login, expanded genres and actors, and an installable Home Screen app.

## Capabilities and Constraints

Preserve server-verified authentication, account isolation, watchlists, viewing history, preferences, existing playback integration, and Vercel deployment architecture. TMDB credentials stay server-side. Live catalog and streaming require a connection. Installation uses browser-supported web app installation, including iPhone instructions.

## Brand Commitments

Keep the blue maruya name. The user explicitly chose one new visual theme for everyone, replacing the personal color themes. Personal content and account data remain separate.

## Evidence on Hand

Existing vanilla HTML/CSS/JavaScript application in dist/, Vercel functions in api/, bundled movie artwork and user-provided login photographs. No new commercial claims or fabricated activity statistics.

## Approved Direction

The user approved mockup C, Cinematic streaming: one shared charcoal and coral theme. Existing movie artwork and real per-profile viewing progress replace the explicitly illustrative images and progress in the mockup. The login preview is a separate screen.
